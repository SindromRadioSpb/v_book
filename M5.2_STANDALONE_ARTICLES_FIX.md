## 🐛 ПРОБЛЕМА (User Report)

### Симптомы
При ручном smoke-check пользователь обнаружил:

1. **В колонке Terms отображаются "ה ספר" с ПРОБЕЛОМ** между артиклем и существительным
2. **Search не находит термины:**
   - Поиск "בית ספר" находит только "בית ספר" и "בית ספר גדול"
   - Поиск "בית הספר" НЕ находит результатов
3. **Ожидалось:** "בית הספר" и "בית ספר" должны быть в ОДНОМ кластере

### Диагностика

Создан debug script (`debug_tokenization.py`), который выявил:

```
Input: "בית הספר" (артикль слитно)
→ Canonical key: "בית_ספר" ✅

Input: "בית ה ספר" (артикль отдельно)
→ Canonical key: "בית_ה_ספר" ❌ (РАЗНЫЕ КЛАСТЕРЫ!)
```

### Root Cause

**Canonicalizer** (`canonicalize_hebrew_term`) работал так:
1. Split text на tokens: `["בית", "ה", "ספר"]`
2. Применить `strip_prefixes()` к каждому токену
3. **ПРОБЛЕМА:** `strip_prefixes("ה")` → `"ה"` (НЕ убирается!)

**Почему "ה" не убирается?**

```python
def strip_prefixes(word: str) -> str:
    while len(word) >= 2 and word[0] in HEBREW_PREFIXES:
        # Only strip if we'll have at least 3 chars left
        if len(word) - 1 >= 3:  # ← ЗДЕСЬ ПРОБЛЕМА
            word = word[1:]
```

- Для токена "ה" (длина 1):
  - Условие `len(word) - 1 >= 3` НЕ выполняется (0 < 3)
  - Префикс НЕ удаляется
  - Результат: canonical key содержит "_ה_" вместо того чтобы быть без него

### Когда возникает?

1. **Входной текст содержит пробел:** "ה ספר" (редко, но возможно)
2. **Токенизатор разделяет артикль:** Некоторые NLP движки могут токенизировать "הספר" как ["ה", "ספר"]
3. **Mock engine** не вызывает проблему для "הספר" (слитно), но если во входе пробел — проблема проявляется

## ✅ РЕШЕНИЕ

### Подход

Добавить **фильтрацию standalone articles** ПЕРЕД `strip_prefixes()`:

```python
# 5. Filter standalone articles/prefixes (M5.2 fix for separate articles)
# Remove single-char tokens that are prefixes (e.g., "ה", "ב", "ל")
tokens = [
    tok for tok in tokens
    if not (len(tok) == 1 and tok in HEBREW_PREFIXES)
]
```

### Логика

1. После split на tokens: `["בית", "ה", "ספר"]`
2. **Фильтровать** одиночные префиксы: `["בית", "ספר"]` (убрали "ה")
3. Применить `strip_prefixes`: `["בית", "ספר"]` (без изменений)
4. Join: `"בית_ספר"` ✅

### Преимущества

- ✅ Backward compatible (старые тесты проходят)
- ✅ Handles edge cases (множественные префиксы: "ב ה ספר" → "ספר")
- ✅ Simple and deterministic
- ✅ Works with any tokenizer (Mock, Stanza, etc.)
