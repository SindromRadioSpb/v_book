## 🔧 Troubleshooting

### ⚠️ КРИТИЧНО: "EndUpdateResource failed (110)" - Inno Setup Error

**Симптомы:**
```
Error in installer.iss: Resource update error: EndUpdateResource failed,
try excluding the Output folder from your antivirus software (110)
Compile aborted.
```

**Причина:** Windows Defender / антивирус блокирует Inno Setup от записи ресурсов в Setup.exe

**Решение (автоматическое - rebuild.ps1 v2):**
- Новая версия `rebuild.ps1` автоматически компилирует в temp, затем копирует с retry
- Если все еще падает, добавьте исключения в Windows Defender:

**Defender Exclusions:**
```powershell
# Run as Administrator
Add-MpPreference -ExclusionPath "J:\Project_Vibe\V_book\installer\output"
Add-MpPreference -ExclusionPath "$env:TEMP\HDLE_Inno_Out_*"
```

**Альтернативно:**
1. Windows Security → Virus & threat protection → Manage settings
2. Exclusions → Add or remove exclusions → Add folder:
   - `J:\Project_Vibe\V_book\installer\output`
   - `C:\Users\Win10_Game_OS\AppData\Local\Temp` (временно)

3. Disable "Controlled folder access" (временно)
4. Run PowerShell as Administrator

### Ошибка: "ModuleNotFoundError: No module named 'app.services.project_exchange'"

**Причина:** Используется старый spec файл (`build/v_book.spec`)

**Решение:** Использовать `hdle_premium_installer.spec`:
```powershell
pyinstaller hdle_premium_installer.spec --clean --noconfirm
```

---

### Ошибка: "Unable to find dist\HDLE_Premium\HDLE_Premium.exe"

**Причина:** EXE не собран перед созданием installer

**Решение:** Сначала собрать EXE (Шаг 1), затем создавать installer (Шаг 3), или использовать `.\rebuild.ps1` (делает оба шага)

---

### Приложение падает при запуске "torch_cpu.dll"

**Причина:** Используется onefile режим вместо onedir

**Решение:** В spec файле проверить:
```python
exe = EXE(
    ...
    exclude_binaries=True,  # Должно быть True (onedir)
    ...
)
```

Пересобрать с актуальным spec файлом.

---

### Экспорт/импорт проектов не работает в установленном приложении

**Причина:** Модули project_exchange не включены в hiddenimports

**Решение:** Использовать актуальный spec (`hdle_premium_installer.spec`), который включает:
```python
hiddenimports=[
    ...
    'app.services.project_exchange',
    'app.services.project_exchange.export_engine',
    'app.services.project_exchange.import_engine',
    'app.ui.dialogs.project_exchange_dialogs',
    ...
]
```
