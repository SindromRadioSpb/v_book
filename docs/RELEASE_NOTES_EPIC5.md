# Release Notes — Epic 5: TM Safety & Layered Extraction

**Версия схемы:** v46 (миграции 045, 046)
**Дата:** 2026-03-22
**Installer:** `HDLE_Premium_Setup.exe` (2426 MB)

---

## Новые возможности

### Три режима переизвлечения терминов

В Terms view добавлен combo box для выбора режима перед запуском извлечения:

| Режим | Когда использовать |
|-------|--------------------|
| **Full Overwrite** | Полный перезапуск — удаляет все кластеры и переизвлекает заново |
| **Merge** | Добавить новые паттерны / документы, не потеряв существующую кюрацию |
| **Replace Layer** | Заменить только конкретный n-граммный слой (например, только биграммы), сохранив остальные |

**Выбор режима сохраняется между сессиями** (QSettings).

#### Full Overwrite — защита от случайного удаления

Перед запуском Full Overwrite появляется **диалог подтверждения** с конкретными числами:
- Сколько кластеров будет удалено
- Сколько TM-записей потеряют связь с кластером

Диалог показывается только если есть реальная угроза. Если кластеров нет — запуск без предупреждения.

#### Merge — безопасное добавление

- Существующие кластеры и их кюрация (approved/rejected) **не затрагиваются**
- Новые ngrams добавляются, старые остаются
- Можно запускать повторно — операция идемпотентна

#### Replace Layer — точечная замена

- Удаляет только кластеры указанного n-набора (например, только `[2]` или только `[3]`)
- Кластеры других слоев и NP-кластеры **не затрагиваются**
- Полезно при изменении словаря стоп-слов или параметров для конкретного n без переработки всего проекта

### Провенанс TM-записей

Каждая запись в Translation Memory теперь хранит историю своего происхождения:

- **Из какого кластера** была промотирована (permanent snapshot, не FK)
- **Параметры извлечения** в момент промоции (SHA-256 hash)
- **Run ID** — ссылка на конкретный запуск извлечения

#### Индикатор источника в TM панели

Новая колонка **«Src»** рядом с каждой TM-записью:

| Индикатор | Значение |
|-----------|----------|
| ● зелёный | Запись связана с живым кластером (`linked`) |
| ● красный | Кластер-источник удалён (`source_cluster_missing`) |
| ● серый | Запись создана вручную (`manual`) |

При наведении на красный индикатор — tooltip с ID исходного кластера и датой промоции.

## Совместимость

- **Схема обновляется автоматически** при первом запуске (миграции 045 и 046).
- **Существующие TM-записи** получают `source_status = manual` (провенанс не известен для старых записей — это нормально).
- **Существующие извлечения** сохраняются без изменений.
- **API backward-compatible**: вызовы с `overwrite=False` автоматически маппируются на режим Merge.

---

## Известные ограничения

- **Replace Layer для NP-слоя** не поддерживается. Workaround: Merge с включённым NP.
- **Merge не обновляет частоты** существующих кластеров — только добавляет новые. Для обновления статистики используйте Full Overwrite.
- **Кластер `[2,3]`** не удаляется при Replace Layer `[2]` — только точное совпадение n-набора.

---

## Миграция

Миграции 045 и 046 применяются автоматически при запуске приложения.
Перед первым запуском новой версии **создаётся автоматический backup** базы данных.

Ручной запуск не требуется.
