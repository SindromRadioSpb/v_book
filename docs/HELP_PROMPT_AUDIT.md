# Prompt Audit — Справка

**Prompt Audit Panel** — инструмент для просмотра и анализа трейсов промптов,
записанных во время работы с переводчиком. Позволяет понять, что именно
было передано модели и как она сформировала ответ.

---

## Открытие панели

- Меню **Tools → Prompt Audit Panel**
- Или из вкладки «Policy Editor» в Help Center

---

## Что записывается в трейс

Каждая запись трейса содержит:

| Поле | Описание |
|---|---|
| **trace_id** | Уникальный идентификатор запроса |
| **policy_id** | Применённая prompt policy |
| **source_text** | Исходный текст для перевода |
| **effective_prompt** | Полный текст промпта, переданного модели |
| **sampling_params** | Параметры семплирования (температура, top-p и т. д.) |
| **translated_text** | Результат перевода |
| **content_kind** | Тип контента (слово, предложение, текст) |
| **created_at** | Время выполнения запроса |
| **provider_id** | Провайдер, выполнивший перевод |

> Полный список полей доступен после экспорта трейса в JSON.

---

## Как включить запись трейсов

1. Откройте **Provider Settings** → вкладка **Advanced**.
2. Включите **Advanced Mode** (флажок «Enable Advanced Mode»).
3. Установите флажок **«Record prompt traces for Audit panel»**.
4. Нажмите **Save**.
5. Выполните перевод — трейс появится в списке Prompt Audit Panel.

> Трейсы записываются только для переводов, выполненных *после* включения флажка.
> Ранее выполненные переводы в историю не добавляются.

---

## Работа со списком трейсов

### Выбор записи
Кликните на запись в списке — в правой панели отобразятся подробности.

### Навигация
Используйте клавиши ↑/↓ для перехода между записями.

### Ограничение хранения
В памяти хранятся последние **100 трейсов**. При превышении лимита
старые записи автоматически удаляются.

> Трейсы хранятся только в рамках текущей сессии.
> После перезапуска приложения история очищается.

---

## Действия с трейсами

### Copy Trace JSON
Копирует трейс выбранной записи в буфер обмена в формате JSON.
Удобно для вставки в текстовый редактор или передачи коллегам.

### Export to File
Сохраняет трейс в `.json` файл на диск.
Откроется диалог выбора места сохранения.

### Compare with Previous
Открывает окно сравнения текущего трейса с предыдущим (side-by-side).
Требует минимум 2 записи в истории.

Удобен для:
- сравнения двух разных policy на одном тексте,
- анализа влияния параметров семплирования,
- отладки неожиданных результатов.

## Практические сценарии

### Сценарий 1: Почему перевод получился именно таким?
1. Убедитесь, что трассировка включена (Policy Editor).
2. Выполните перевод.
3. В Prompt Audit выберите запись.
4. Изучите поле **effective_prompt** — именно этот текст видела модель.

### Сценарий 2: Сравнение двух policy
1. Включите трассировку.
2. Переведите текст с policy A.
3. Смените policy на B, переведите тот же текст.
4. Нажмите **Compare with Previous** — увидите оба промпта рядом.

### Сценарий 3: Сохранение доказательства перевода
1. Выберите трейс в списке.
2. Нажмите **Export to File**.
3. Сохраните JSON — в нём полная информация о запросе и параметрах.

## Частые вопросы

**Список пуст, хотя я перевожу.**
→ Трассировка не включена. Перейдите в Policy Editor и установите
флажок «Record prompt traces».

**Кнопка «Compare with Previous» неактивна.**
→ В истории менее 2 записей. Выполните ещё один перевод.

**Трейсы исчезли после перезапуска.**
→ Это ожидаемое поведение: хранение только в памяти сессии.
Экспортируйте важные трейсы через «Export to File».

**В трейсе нет поля effective_prompt.**
→ Провайдер не вернул трассировочные данные. Убедитесь, что используете
локальный HY-MT провайдер с поддержкой трассировки.

---

## Ограничения

- Трейсы не сохраняются между сессиями.
- Максимум 100 трейсов в памяти.
- Запись доступна только в Advanced Mode.
- Пакетный перевод (Batch) и перевод словаря также поддерживают трассировку,
  если Advanced Mode и флажок включены.
