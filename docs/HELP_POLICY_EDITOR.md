# Policy Editor — Справка

Вкладка **Policy Editor** открывает расширенный режим управления prompt policy:
кастомные настройки, параметры семплирования и запись трассировки промптов.

---

## Включение Advanced Mode

1. Откройте **Provider Settings** → вкладка **Advanced**.
2. Установите флажок **«Enable Advanced Mode»**.
3. Остальные элементы управления станут активными.

> После отключения Advanced Mode система возвращается к policy из Basic Mode.
> Настройки Advanced Mode сохраняются и будут восстановлены при следующем открытии.

---

## Выбор кастомной Policy

В поле **Policy ID** введите или выберите из списка идентификатор policy.
Нажмите **Apply** для немедленного применения или **Save** для сохранения.

Примеры ID:

| ID | Назначение |
|---|---|
| `sentence_ru` | Стандартный режим для предложений |
| `sentence_ru_precise` | Более точный, но медленный |
| `word_ru_glossary` | Словарные записи с учётом глоссария |

> Если вы вводите ID вручную, убедитесь, что он зарегистрирован на сервере провайдера.
> Неизвестный ID приведёт к ошибке перевода.

---

## Параметры семплирования

Advanced Mode позволяет переопределить параметры генерации текста:

| Параметр | Описание | Типичный диапазон |
|---|---|---|
| **Temperature** | Случайность вывода. Ниже = точнее, выше = разнообразнее | 0.0 – 1.0 |
| **Top-p** | Nucleus sampling. Ограничивает выборку по вероятности | 0.5 – 1.0 |
| **Repetition penalty** | Штраф за повторение токенов | 1.0 – 1.5 |
| **Max new tokens** | Максимальная длина ответа модели | 64 – 512 |

> Значения по умолчанию определяются выбранной policy и обычно оптимальны.
> Изменяйте их только при понимании эффекта каждого параметра.

---

## Запись трассировки промптов

Флажок **«Record prompt traces for Audit panel»** включает запись
полного трейса для каждого перевода:

- что именно было передано модели (эффективный промпт),
- какие параметры семплирования были применены,
- результат и метаданные ответа.

**Условия записи:**
- Advanced Mode должен быть включён.
- Флажок «Record prompt traces» должен быть установлен.
- Запись ведётся только для переводов, выполненных после включения флажка.

> Трейсы хранятся только в памяти текущей сессии (до 100 записей).
> После перезапуска приложения история очищается.

Просмотр записанных трейсов — во вкладке **Prompt Audit** (меню Tools → Prompt Audit Panel).

---

## Типичные сценарии

### Сценарий 1: Отладка неточного перевода
1. Включите Advanced Mode.
2. Установите флажок «Record prompt traces».
3. Выполните перевод проблемного текста.
4. Откройте **Tools → Prompt Audit Panel**.
5. Выберите запись в списке и изучите эффективный промпт.

### Сценарий 2: Сравнение двух policy
1. Включите трассировку.
2. Переведите один и тот же текст с policy A.
3. Смените Policy ID на B, переведите снова.
4. В Prompt Audit используйте кнопку **«Compare with Previous»**.

### Сценарий 3: Тонкая настройка температуры
1. Включите Advanced Mode.
2. Установите температуру 0.3 для более детерминированного перевода.
3. Сравните результат с результатом при температуре 0.7.

---

## Частые ошибки

- **«Record prompt traces» недоступен** — убедитесь, что Advanced Mode включён.
- **Трейсы не появляются в Prompt Audit** — флажок должен быть установлен
  *до* выполнения перевода.
- **Неизвестный Policy ID** — проверьте ID в документации провайдера или
  выберите из выпадающего списка.
- **Перевод не изменился после смены параметров** — убедитесь, что нажали **Save**.

---

## Связанные вкладки

- **Prompt Policy** — выбор policy в базовом режиме без дополнительных настроек.
- **Prompt Audit** — просмотр, экспорт и сравнение записанных трейсов.
